## 常见问题

**Q: 登录失败？**
> 检查账号密码，初始账号为 `admin`，首次登录会引导设置密码。

**Q: 标书解析失败？**
> 请使用文字版 PDF 或 Word，扫描件图片暂不支持。

**Q: AI 生成内容不准？**
> 上传更多相关历史标书到知识库，RAG 检索质量会显著提升。

**Q: 如何更新版本？**
> 下载最新版 `Tender.exe` 替换旧文件，`data` 文件夹中的数据不会丢失。
