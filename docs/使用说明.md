# Tender 使用说明

> 制造业中小企业 AI 文档助手
> 版本：v1.0 MVP | 更新：2026-05-15

---

## 一、产品概述

### 1.1 什么是 Tender

Tender 是一款面向制造业中小企业的 **AI 文档助手**，专注于投标标书的智能解析与生成，同时提供企业知识库问答能力。

**核心场景：**
- 📄 **投标标书制作** — 上传招标文件，AI 自动生成完整标书草稿
- 📚 **企业知识库问答** — 上传企业内部文档，AI 基于文档回答问题
- 🔍 **标书查重与质检** — 自动检测重复内容、废标风险、格式规范
- 📖 **历史版本管理** — 每次生成自动保存版本，支持对比和恢复

### 1.2 产品优势

| 优势 | 说明 |
|------|------|
| **本地部署** | 所有数据存在本地服务器，不上传云端 |
| **开箱即用** | Windows 单文件，双击运行，无需 Docker |
| **行业垂直** | 专为制造业标书场景优化，非通用 AI 助手 |
| **AI 驱动** | 基于 DeepSeek 大模型，理解招标文件的行话和逻辑 |

### 1.3 系统要求

- 操作系统：Windows 10/11 或 Windows Server 2019+
- 内存：4GB+ RAM
- 硬盘：10GB+ 可用空间
- 网络：需要连接 AI 模型 API（可配置代理）

## 二、安装与启动

### 2.1 获取程序

从 GitHub 下载最新版本：
```
https://github.com/cnchaoge/tender/releases
```

下载 `Tender.exe`（Windows 单文件版）

### 2.2 首次启动

1. 双击运行 `Tender.exe`
2. 首次运行会提示设置管理员密码
3. 设置密码后，浏览器自动打开 `http://localhost:8000`
4. 使用账号 `admin` 和刚才设置的密码登录

### 2.3 配置 AI API Key

> Tender 需要连接 AI 模型服务才能正常工作。

1. 登录后进入 **设置** 页面
2. 在「AI 模型配置」中填入 DeepSeek API Key
3. 可选配置通义千问、智谱等备选模型
4. 保存后即可开始使用

**如何获取 API Key：**
- DeepSeek：https://platform.deepseek.com 注册后创建 API Key
- 通义千问：阿里云百炼平台

### 2.4 开发模式运行（可选）

如需修改代码或调试，可从源码启动：

```bash
cd tender/web
npm install
npm run dev     # 前端：http://localhost:5173

cd tender
./start.sh      # 后端：http://localhost:8000
```

## 三、快速入门

### 3.1 十分钟上手

**第一步：上传知识库素材（5分钟）**

知识库是 AI 生成标书时的参考资料库。上传越多的历史标书、产品方案、公司介绍，生成的内容就越精准。

1. 进入「知识库」页面
2. 点击「上传文档」支持 PDF、Word、Markdown、TXT 格式
3. 文档会自动切片、存入向量数据库
4. 上传完成后即可用于 RAG 问答和标书生成

**第二步：上传招标文件（2分钟）**

1. 进入「标书生成」页面
2. 点击上传招标文件（PDF 或 DOCX）
3. 系统自动解析项目名称、工期、资质要求、评分标准

**第三步：选择素材，生成标书（3分钟）**

1. 系统已自动推荐相关素材，勾选需要的文档
2. 选择投标策略：
   - **综合均衡型** — 推荐，技术和价格平衡
   - **技术优先型** — 突出技术方案，适合专家评标
   - **成本控制型** — 价格优先，适合最低价中标
3. 点击「生成投标标书」
4. AI 逐章节生成，可实时看到进度
5. 生成完成后下载 Word 文件

## 四、功能详解

### 4.1 知识库管理

**上传文档**

点击「上传文档」或拖拽文件到上传区。支持批量上传。

**文档切片**

系统自动将文档按 500 字/片切割，存入向量数据库。切片后的内容用于 RAG 检索。

**文档检索**

上传后可直接在知识库内搜索文档名称或内容。

**删除文档**

选中文档后点击删除，文档及其切片数据会从向量库中清除。

### 4.2 标书生成

**招标文件解析**

上传招标文件后，系统自动提取：

| 提取字段 | 说明 |
|------|------|
| 项目名称 | 招标项目的完整名称 |
| 工期 | 招标要求的完成时间 |
| 资格要求 | 投标人的资质条件 |
| 资质要求 | 需要具备的证书或许可 |
| 评分标准 | 技术标/商务标各部分占比和评分方式 |
| 废标条件 | 触发了则直接废标的条款 |

解析结果可手动修正，确认无误后进入下一步。

**素材选择**

系统基于招标文件自动推荐相关素材。从知识库中匹配历史标书、资质证书、产品方案等。

可手动调整选中的素材（增加或移除）。

**投标策略**

| 策略 | 适用场景 |
|------|----------|
| 综合均衡型 | 大多数招标，推荐默认 |
| 技术优先型 | 专家评标、技术权重高的项目 |
| 成本控制型 | 最低价中标、价格战项目 |

**生成过程**

生成过程分为 5 个阶段，全程实时展示：

```
[████░░░░░░░░░░░░░░░] 解析招标文件   20%
[████████████░░░░░░░] 检测废标风险   40%
[████████████████░░░] 生成正文     60%
[████████████████████] AI 质检     80%
[████████████████████] 完成         100%
```

每个章节独立生成，可在进度条中看到各章节的状态。

**标书质检**

生成完成后自动进行 AI 质检：

- 内容完整性：是否覆盖了招标文件的所有要求
- 废标风险：是否有触犯废标条件的表述
- 格式规范：是否缺少签字盖章位、页眉页脚等
- 标书查重：与知识库已有标书的重复度

**历史版本**

每次生成自动保存为一个版本，可在「历史版本」中：

- 查看历史版本的生成时间、策略类型
- 对比两个版本的差异
- 基于某个历史版本重新生成

### 4.3 企业 RAG 问答

**上传文档到知识库**

RAG 问答基于知识库中的文档。确保需要 AI 查阅的文档已上传到知识库。

**开始问答**

1. 进入「RAG 问答」页面
2. 在输入框中用自然语言提问
3. AI 基于知识库中的文档检索答案
4. 回答中会标注参考来源（来源文件名）

**多轮对话**

支持追问和澄清，AI 会记住对话上下文。

### 4.4 管理后台

**用户管理**

- 添加/编辑/删除用户
- 设置用户角色（管理员/普通用户）
- 修改密码

**AI 模型配置**

- 配置 DeepSeek、通义千问等模型的 API Key
- 选择默认使用的模型
- 配置 Embedding 模型（用于知识库切片向量化）

**系统配置**

- 修改端口号（默认 8000）
- 查看服务运行状态

## 五、功能限制与说明

### 5.1 当前版本（v1.0 MVP）暂不支持

- 多租户隔离（不同企业共用同一个部署实例）
- 钉钉/企业微信渠道集成
- 本地大模型推理（必须连接云端 API）
- OCR 图片文字识别（建议使用文字版 PDF）
- Excel 台账自动化
- 按调用量计费

### 5.2 使用注意事项

**标书质量**

AI 生成的标书是草稿，需要人工审核确认后再提交。Tender 辅助人工工作，不替代专业判断。

**数据安全**

所有数据（招标文件、知识库、生成记录）都存储在本地服务器。不上传到任何云端服务器（除 AI API 调用外）。

**AI API 成本**

标书解析和生成会消耗 AI Token，建议在后台关注 Token 使用量，在「设置」中配置额度限制。

**文件格式**

推荐使用文字版 PDF 或 Word 文档。扫描件图片型 PDF 无法提取文字，暂时不支持。

## 六、常见问题

### Q1：登录失败，提示"认证失败"

- 检查账号密码是否正确
- 确认是否已设置过初始密码（首次启动时会引导设置）
- 重置密码请联系管理员

### Q2：标书解析失败，显示"解析失败"

可能原因：
- 文件不是文字版（扫描件图片），建议使用文字版 PDF
- 文件格式不支持，换成 PDF 或 DOCX 格式
- 网络异常，AI 模型调用超时

### Q3：生成标书时报错"DashScope API Key 无效"

Embedding 模型 API Key 配置错误。进入「设置」→「Embedding 配置」修正 API Key。

### Q4：生成的内容与招标文件不符

- 检查解析结果中的「项目名称」「工期」等字段是否正确
- 解析结果可以手动修正后再生成
- 如果招标文件格式特殊，可能需要补充行业关键词

### Q5：如何更新到新版本？

1. 下载最新版的 `Tender.exe`
2. 替换旧文件（建议先备份 `data` 文件夹）
3. 重启程序

> 注：数据文件在 `data` 文件夹中，更新程序不会清除数据。

### Q6：Mac/Linux 可以用吗？

当前版本仅支持 Windows 部署。Mac/Linux 用户可通过虚拟机或远程访问 Windows 服务器使用。

## 七、技术架构

```
┌─────────────────────────────────────┐
│          Tender 客户端              │
│  浏览器 (Vue3 SPA)                    │
└─────────────────────────────────────┘
                │ HTTP
                ↓
┌─────────────────────────────────────┐
│          FastAPI 后端服务             │
│  Python + SQLite + ChromaDB           │
│  ├── 认证 (JWT)                       │
│  ├── RAG 检索引擎                    │
│  ├── 标书解析/生成                   │
│  ├── 废标检测                        │
│  └── 管理后台                        │
└─────────────────────────────────────┘
                │ HTTPS
                ↓
┌─────────────────────────────────────┐
│       AI 模型 API (DeepSeek 等)       │
└─────────────────────────────────────┘
```

**数据存储：**

- SQLite：元数据（用户、文档记录、配置等）
- ChromaDB：向量数据（文档切片）
- 文件系统：`data/uploads/` 原始文件，`data/generated/` 生成文件
