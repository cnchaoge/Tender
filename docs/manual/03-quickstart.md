# 三、快速入门

## 十分钟上手流程

整个使用流程分为 3 步：

```
上传知识库 → 上传招标文件 → 生成标书
    5分钟          2分钟          3分钟
```

---

## 第一步：上传知识库素材

知识库是 AI 生成标书时的 **参考资料库**。上传越多的历史标书、产品方案、公司介绍，生成的内容就越精准。

**步骤：**

1. 进入「**知识库**」页面
2. 点击「**上传文档**」
3. 支持 PDF、Word、Markdown、TXT 格式，可批量上传
4. 文档自动切片并存入向量数据库
5. 上传完成后即可用于 RAG 问答和标书生成

---

## 第二步：上传招标文件

1. 进入「**标书生成**」页面
2. 点击上传招标文件（PDF 或 DOCX）
3. 系统自动解析，提取：
   - 项目名称、工期
   - 资格要求、资质要求
   - 评分标准（技术标/商务标各部分占比）
   - 废标条件

4. 检查解析结果，手动修正（如有误）
5. 确认无误后进入下一步

---

## 第三步：生成标书

**步骤：**

1. **选择素材** — 系统已自动推荐相关素材，勾选需要的文档

2. **选择投标策略：**

   | 策略 | 适用场景 |
   |------|----------|
   | 综合均衡型 ✅ | 大多数招标，推荐默认 |
   | 技术优先型 | 专家评标、技术权重高的项目 |
   | 成本控制型 | 最低价中标、价格战项目 |

3. **点击「生成投标标书」**

4. 实时查看生成进度（5阶段）：
   ```
   [████░░░░░░░░░░░░░░░] 解析招标文件   20%
   [████████████░░░░░░░] 检测废标风险   40%
   [████████████████░░░] 生成正文     60%
   [████████████████████] AI 质检     80%
   [████████████████████] 完成         100%
   ```

5. 生成完成后 **下载 Word 文件**，人工审核后提交
