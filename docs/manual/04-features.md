# 四、功能详解

## 知识库管理

### 上传文档

点击「上传文档」或拖拽文件到上传区。支持批量上传。

### 文档切片

系统自动将文档按 **500 字/片** 切割，存入向量数据库。切片后的内容用于 RAG 检索。

### 文档检索

上传后可直接在知识库内搜索文档名称或内容。

### 删除文档

选中文档后点击删除，文档及其切片数据会从向量库中清除。

## 标书生成

### 招标文件解析

上传招标文件后，系统自动提取以下字段：

| 提取字段 | 说明 |
|------|------|
| 项目名称 | 招标项目的完整名称 |
| 工期 | 招标要求的完成时间 |
| 资格要求 | 投标人的资格条件 |
| 资质要求 | 需要具备的证书或许可 |
| 评分标准 | 技术标/商务标各部分占比和评分方式 |
| 废标条件 | 触发了则直接废标的条款 |

解析结果可手动修正，确认无误后进入下一步。

### 素材选择

系统基于招标文件自动推荐相关素材。从知识库中匹配历史标书、资质证书、产品方案等。可手动调整选中的素材（增加或移除）。

### 投标策略

| 策略 | 适用场景 |
|------|----------|
| 综合均衡型 | 大多数招标，推荐默认 |
| 技术优先型 | 专家评标、技术权重高的项目 |
| 成本控制型 | 最低价中标、价格战项目 |

### 标书质检

生成完成后自动进行 AI 质检：

- ✅ **内容完整性** — 是否覆盖了招标文件的所有要求
- ⚠️ **废标风险** — 是否有触犯废标条件的表述
- 📋 **格式规范** — 是否缺少签字盖章位、页眉页脚等
- 🔍 **标书查重** — 与知识库已有标书的重复度

### 历史版本

每次生成自动保存为一个版本，可在「历史版本」中：

- 查看历史版本的生成时间、策略类型
- 对比两个版本的差异
- 基于某个历史版本重新生成

## 企业 RAG 问答

### 上传文档到知识库

RAG 问答基于知识库中的文档。确保需要 AI 查阅的文档已上传到知识库。

### 开始问答

1. 进入「**RAG 问答**」页面
2. 在输入框中用自然语言提问
3. AI 基于知识库中的文档检索答案
4. 回答中会标注参考来源（来源文件名）

### 多轮对话

支持追问和澄清，AI 会记住对话上下文。

---

## 管理后台

### 用户管理

- 添加 / 编辑 / 删除用户
- 设置用户角色（管理员 / 普通用户）
- 修改密码

### AI 模型配置

- 配置 DeepSeek、通义千问等模型的 API Key
- 选择默认使用的模型
- 配置 Embedding 模型（用于知识库切片向量化）

### 系统配置

- 修改端口号（默认 8000）
- 查看服务运行状态
