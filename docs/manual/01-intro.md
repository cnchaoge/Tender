# 一、产品概述

## 什么是 Tender

Tender 是一款面向 **制造业中小企业** 的 AI 文档助手，专注于投标标书的智能解析与生成，同时提供企业知识库问答能力。

### 核心场景

| 场景 | 说明 |
|------|------|
| 📄 **投标标书制作** | 上传招标文件，AI 自动生成完整标书草稿 |
| 📚 **企业知识库问答** | 上传企业内部文档，AI 基于文档回答问题 |
| 🔍 **标书查重与质检** | 自动检测重复内容、废标风险、格式规范 |
| 📖 **历史版本管理** | 每次生成自动保存版本，支持对比和恢复 |

---

## 产品优势

| 优势 | 说明 |
|------|------|
| 🏠 **本地部署** | 数据放在本机 `data/`。默认模型可以是本机 Ollama |
| ⚡ **本机运行** | Python 虚拟环境 + 已构建的前端。无需 Docker，仓库里没有 `Tender.exe` |
| 🎯 **行业垂直** | 专为制造业标书场景优化，非通用 AI 助手 |
| 🤖 **AI 驱动** | 基于 DeepSeek 大模型，理解招标文件的行话和逻辑 |

---

## 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | macOS、Linux 或 Windows。用源码和虚拟环境运行，不需要 Windows 虚拟机 |
| 内存 | 4GB+ RAM |
| 硬盘 | 10GB+ 可用空间 |
| 网络 | 本机 Ollama 可以不连外网。选用云端模型时需要能访问对应 API |
