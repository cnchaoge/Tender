# 五、常见问题

## Q1：登录失败，提示"认证失败"

可能原因：
- 账号密码输入错误
- 未设置过初始密码（首次启动时会引导设置）
- Token 过期

**解决方法：** 联系管理员重置密码。

---

## Q2：标书解析失败，显示"解析失败"

可能原因：
- 文件不是文字版（扫描件图片），建议使用文字版 PDF
- 文件格式不支持，换成 PDF 或 DOCX 格式
- 网络异常，AI 模型调用超时

**解决方法：** 确认文件是文字版 PDF 或 Word，可先复制文字内容保存为 Markdown 再试。

---

## Q3：生成标书时报错"DashScope API Key 无效"

Embedding 模型 API Key 配置错误。

**解决方法：** 进入「系统设置」→「Embedding 配置」修正 API Key，或暂时切换为 Mock Embedder（不调 API，但无法做向量检索）。

---

## Q4：生成的内容与招标文件不符

可能原因：
- 解析结果中的「项目名称」「工期」等字段有误
- 招标文件格式特殊，解析不完整

**解决方法：** 检查解析结果，手动修正后再生成。可补充行业关键词提升解析准确率。

---

## Q5：如何更新到新版本？

1. 下载最新版的 `ClawOSX.exe`
2. 替换旧文件（建议先备份 `data` 文件夹）
3. 重启程序

> 注：数据文件在 `data` 文件夹中，更新程序不会清除数据。

---

## Q6：Mac / Linux 可以用吗？

当前版本仅支持 **Windows 部署**。Mac/Linux 用户可通过虚拟机或远程访问 Windows 服务器使用。

如需 Mac 原生版本，可联系我们单独定制。
